## 泛化标签索引

| 标签 | 条目 | 说明 |
|---|---|---|
| `规范冲突` | DRIFT-0001 | 两份同级规范正文互相矛盾，字面执行只有一种可能，冲突被静默解决 |

标签用于把碎片串成链——同一标签下的条目往往是同一个结构性问题的不同表现。
`生成物` 这个标签值得留意：`scripts/verify.sh` 的 `diagrams` 阶段是它的第一个自动化检查，
若后续条目也落在它下面，说明「生成物缺少再生入口」是一个反复出现的结构性缺口。

## 依赖关系

```text
DRIFT-0001  规范冲突
    │
    └─► 成因：规范正文与它所依据的范式分处两地，两者可独立演进，
              却没有任何检查验证二者一致
```

**这是最有价值的一节。** 单条约束是碎片，依赖链才是知识。

DRIFT-0001 本身已自动化（`./scripts/verify.sh diagrams`），但它的**成因**尚未被覆盖：
那条检查验证的是图与源码一致，不是两份规范互相一致。
若再次出现规范级的同类冲突，应记为新条目并在本条中加一条边——
同一类位置上反复漂移时，处置应从「打补丁」上升到「改设计」。
